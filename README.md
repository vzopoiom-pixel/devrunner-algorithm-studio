## ✨ Features & Architecture

- ⚡ **Multi-Language Execution:** Instant simulation of JVM/runtime memory pool for Java, Python, C++, SQL, and TypeScript.
- ⏱ **Time & Space Complexity Inspector:** Real-time Big-O metrics ($O(\log N)$, $O(1)$, $O(N \log N)$) and structural explanations.
- 🖥 **Integrated Terminal Console:** Execution logs, millisecond runtime stats, and memory utilization monitors.
- 🎨 **Modern Ergonomic UI:** Built with React 18, TypeScript, and Tailwind CSS.

---

## 🛠 Included Algorithmic Suites

- **Java:** Logarithmic Binary Search, Doubly Linked List LRU Cache.
- **Python:** Semi-structured JSON Data Extraction & Stream Aggregation.
- **C++:** In-place Divide & Conquer QuickSort with median pivot.
- **SQL:** CTEs, Window Functions, and Running Revenue Calculations.
