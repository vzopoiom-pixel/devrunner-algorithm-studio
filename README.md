> An interactive web-based code execution sandbox and algorithmic complexity analyzer supporting Java, Python, SQL, and C++.

---

## 🚀 Key Highlights

- ⚡ **Multi-Language Support:** Pre-configured environments and execution templates for Java, Python, C++, SQL, and TypeScript.
- ⏱ **Time & Space Complexity Inspector:** Real-time Big-O analysis for classic data structures and sorting/searching routines.
- 🖥 **Integrated Terminal:** Instant execution logs, memory footprint metrics, and millisecond runtime measurements.
- 🎨 **Clean Developer UI:** Ergonomic dark theme with code formatting, line inspection, and snippet library.

---

## 🛠 Included Algorithmic Suites

1. **Java:** Logarithmic Binary Search, Doubly Linked List LRU Cache.
2. **Python:** Semi-structured JSON Data Extraction & Stream Aggregation.
3. **C++:** In-place Divide & Conquer QuickSort with median pivot.
4. **SQL:** CTEs, Window Functions, and Running Revenue Calculations.
