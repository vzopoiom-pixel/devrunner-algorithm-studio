`Java 21 LTS` • `Python 3.12` • `C++ 20` • `PostgreSQL SQL` • `TypeScript 5` • `React 18`

> High-performance developer sandbox and algorithmic complexity inspector supporting Java, Python, SQL, and C++.

---

## 📌 Project Overview

**DevRunner Studio** is an ergonomic developer environment designed for real-time code execution, data structure exploration, and Big-O runtime analysis.

### ✨ Key Features:
- ⚡ **Multi-Language Execution:** Instant simulation of JVM / runtime execution environments for Java, Python, C++, SQL, and TypeScript.
- ⏱ **Time & Space Complexity Analyzer:** Real-time Big-O metrics ($O(\log N)$, $O(1)$, $O(N \log N)$) with in-depth structural explanations.
- 🖥 **Integrated Execution Terminal:** Process exit codes, millisecond execution timers, and memory allocation counters.
- 🎨 **Modern Ergonomic UI:** Built with React 18, TypeScript, and clean Tailwind CSS styling.

---

## 🛠 Included Algorithmic Suites

1. **Java:** Logarithmic Binary Search, Doubly Linked List LRU Cache.
2. **Python:** Semi-structured JSON Data Extraction & Stream Aggregation.
3. **C++:** In-place Divide & Conquer QuickSort with median pivot.
4. **SQL:** CTEs, Window Functions, and Running Revenue Calculations.
